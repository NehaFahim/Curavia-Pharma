## Overview

**Curavia Pharma** is a premium pharmaceutical website concept designed to showcase a modern, research-driven healthcare brand through an immersive and interactive digital experience.

The project brings together pharmaceutical manufacturing, quality assurance, research and development, formulation categories, and global supply concepts in a visually engaging interface.

With a dark green and teal visual identity, clean layouts, scientific imagery, interactive sections, and animation-driven storytelling, Curavia Pharma demonstrates how modern web technologies can create a polished digital experience for the pharmaceutical industry.

🔗 **Live Website:** [https://curavia-pharma.vercel.app/](https://curavia-pharma.vercel.app/)

## Features

- **Modern Hero Section** — A premium landing experience featuring pharmaceutical messaging, interactive visuals, and clear calls to action.
- **About Curavia** — Brand introduction, philosophy, and quality-focused approach.
- **Manufacturing & Capabilities** — A structured presentation of material control, process discipline, quality checkpoints, and production workflows.
- **Interactive Quality Systems** — Six core disciplines covering advanced manufacturing, quality assurance, global standards, R&D, reliable supply, and regulatory excellence.
- **Quality Analytics Dashboard** — A dashboard-inspired interface for illustrating batch traceability, analytical review, and quality-control workflows.
- **Interactive Process Journey** — A four-stage storytelling experience: Discover, Develop, Validate, and Deliver.
- **Product Portfolio** — Eight formulation categories, including pharmaceutical tablets, hard gel capsules, oral solutions, injectables, nutraceuticals, healthcare supplements, specialty formulations, and pediatric solutions.
- **Global Presence** — A visual representation of international regions and global supply concepts.
- **Facilities & Research Gallery** — Scientific and pharmaceutical facility imagery presented in a visual gallery.
- **Research & Development** — A dedicated section highlighting formulation thinking, analytical discipline, and continuous improvement.
- **Quality & Standards** — Illustrative representations of pharmaceutical quality frameworks and regulatory considerations.
- **Contact & Enquiry Interface** — A structured enquiry form with contact fields and file attachment support.
- **Newsletter Section** — A dedicated interface for industry updates and research-related content.
- **Animations & Visual Effects** — Motion-driven interactions for a more immersive browsing experience.
- **Responsive User Interface** — A modern layout designed for different screen sizes.

## Design Philosophy

The visual direction of Curavia Pharma combines a premium pharmaceutical aesthetic with modern interactive web design.

- **Dark Green & Teal:** A distinctive medical-tech identity.
- **Clean Light Sections:** Readable content and clear information hierarchy.
- **Scientific Imagery:** Laboratory, manufacturing, and research-inspired visuals.
- **Interactive Storytelling:** Structured content enhanced by animation and motion.
- **Modern Typography:** A clean presentation designed for readability.
- **Responsive Layouts:** A consistent browsing experience across screen sizes.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd YOUR_PROJECT_FOLDER
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the website**

Visit [http://localhost:3000](http://localhost:3000/) in your browser.

> Replace `YOUR_REPOSITORY_URL` and `YOUR_PROJECT_FOLDER` with your actual repository URL and project directory name.

### Production Build

Build the project for production:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

## Deployment

The project is deployed on Vercel.

**Live URL:** [curavia-pharma.vercel.app](https://curavia-pharma.vercel.app/)

To deploy your own version, connect your GitHub repository to [Vercel](https://vercel.com/) and configure the project using the settings required by your repository.

## Important Notes

Curavia Pharma is a **fictional concept brand developed for portfolio and demonstration purposes**.

- Company history, operational figures, market presence, and business information are illustrative.
- Certification badges and standards-related visuals do not establish actual regulatory approval or certified compliance.
- Product categories are presented for demonstration purposes and do not represent verified commercial products.
- Contact enquiries are validated but are not stored or sent.
- Real enquiry handling, newsletter subscriptions, and other backend functionality would require additional integrations.
